# Actividad 2.6 - Backend con Node.js + Express + Cheerio

## Descripción

El objetivo fue desarrollar un backend utilizando Node.js, Express y Cheerio para procesar un archivo HTML llamado `catalogo.html` y entregar la información de los libros mediante endpoints REST en formato JSON.

El sistema lee el archivo HTML desde el servidor, extrae los datos utilizando selectores CSS con Cheerio y devuelve respuestas estructuradas usando Express.

---

# Objetivo

Procesar HTML desde backend utilizando Cheerio para extraer información del catálogo digital de la Biblioteca IP Santo Tomás y exponer los datos mediante una API REST.

---

# Tecnologías utilizadas
